How to name chip resistor, capacitor and inductor footprints

Chip parts use a short name built from the metric body size and the maximum height. The size code is metric, not the imperial code printed in catalogues.

The formula

RESC / CAPC / INDC + length + width X height + density RESC1608X55N = chip resistor, 1.6 × 0.8 mm body (0603 imperial), 0.55 mm max height

Step by step

  1. Prefix – RESC resistor, CAPC capacitor, CAPCP polarized capacitor, INDC inductor, DIOC diode, LEDM molded LED.
  2. Length and width – one digit each side of the decimal point: 1.6 → 16, 0.8 → 08, giving 1608. Further digits are dropped: 1.25 → 12.
  3. Height – T maximum × 100: 0.55 → 55, 0.90 → 90.
  4. Density – N, M or L.

Common mistakes

Imperial code in the nameAn 0603 resistor is RESC1608…. RESC0603… means a much smaller 0201 part.
One name for all capacitorsAn 0603 MLCC can be 0.8 or 1.0 mm thick. Different heights give different names – CAPC1608X90N vs CAPC1608X110N – so the 3D model and placement height stay correct.
0805 size codeThe width 1.25 mm becomes 12 – only one digit after the decimal point is kept – so 0805 is 2012.
