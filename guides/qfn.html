How to name a QFN footprint (IPC-7351B)

QFN, SON and DFN names describe pitch, body size, height and pin count. The two things people get wrong are the order of the body dimensions and the thermal pad.

The formula

QFN + pitch P + body width X body length X height - pin count + density QFN50P500X500X100-33N = 0.50 mm pitch, 5.00 × 5.00 mm body, 1.00 mm max height, 32 pins + thermal pad, nominal density

Step by step

  1. Pitch – e from the datasheet, × 100: 0.50 mm → 50P, 0.40 mm → 40P.
  2. Body width and length – nominal values × 100, no leading zeros: 5.00 → 500, 3.50 → 350. Width comes first.
  3. Height – the maximum A value × 100: 1.00 → 100, 0.80 → 80.
  4. Pin count – signal pins, plus one if there is an exposed thermal pad: 32 + pad → -33.
  5. Density – N nominal for most boards, M most material, L least material.

SON (two-sided) uses the same pattern with the prefix SON. DFN uses body size and height without a pitch: DFN300X300X80-8N.

Common mistakes

Forgetting the thermal padA 32-pin QFN with an exposed pad is -33, not -32. Two parts with and without a pad would otherwise get the same name.
Using typical heightDatasheets list A as min / nom / max. The name uses the maximum, because it is what limits clearance.
Leading zerosWrite 350, not 0350, and 80, not 080.
