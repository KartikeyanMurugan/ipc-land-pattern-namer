Footprint naming guides

Short, practical guides to IPC-7351B land pattern names – which datasheet value goes where, and the mistakes that create duplicate or wrong footprints.

  • QFN, SON and DFNThermal pad in the pin count, body width vs length. QFN50P500X500X100-33N
  • SOIC, SOP, SSOP, TSSOPLead span E vs body width E1. SOIC127P600X175-8N
  • Chip resistors, capacitors, inductors0603 imperial is 1608 metric. RESC1608X55N
  • SOT-23, SOT-23-5, SOT-223Which pitch to use when pins are missing. SOT95P280X145-5N
