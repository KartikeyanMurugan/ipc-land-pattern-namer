## Value and rounding policy

- All dimensions in millimetres.
- Spans, pitch and body sizes use the nominal value = (min + max) / 2 when both are given.
- Heights and lead widths use the maximum value.
- Format h: value x 100, rounded half up (0.635 -> 64), no leading zeros.
- Format c: one digit each side of the decimal point, further digits dropped (1.25 -> 12).
- Thermal pad size: T + width x 100, plus X + length x 100 when not square, after the density letter (T300, T300X200). Source PCBLIB-T.
- Non-finite numbers, values <= 0, unknown density/level letters and invalid variants produce no name.

## Evidence levels

- **Datasheet verified** – a real part checked by a PCB designer (`test/datasheet-cases.json`, status `verified`)
- **Source example** – reproduces an example printed in the source document
- **Derived example** – formula from the source, example built by the project, not printed in the source
- **Formula only** – formula from the source, no example yet
