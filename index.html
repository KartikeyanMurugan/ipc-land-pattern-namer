    How it works

    1. Pick the package family

      Search by package type. Each family asks only for the dimensions its name needs.

    2. Type the datasheet values

      Enter min and max as printed. The tool takes the nominal for spans and the maximum for height, the way IPC names are built.

    3. Copy and reuse

      Copy the name, share a link that reopens the same part, or download the JSON record for a footprint generator.

    Naming rules used

    ValueRuleExample
    Pitch, lead span, body, heightmm × 100, rounded, no leading zeros1.27 mm → 127, 0.50 mm → 50
    Chip body (RESC, CAPC, INDC …)One digit each side of the decimal point1.6 × 0.8 mm → 1608
    Pin quantityAfter a dash; a thermal pad counts as one more pin-33 for 32 pins + pad
    Hidden / deleted / reversed pinsUsed_package, package_used, R-20_24, -24_20, -20R
    Last letter, SMDDensity level M (most), N (nominal), L (least); none for BGARESC1608X55N
    Last letter, through-holeFabrication level A, B or CDIP762W52P254L1905H508Q14B
    Notes on the source and known issues

    Rules follow the public IPC-7351B naming convention summary (PCB Matrix, 2009). IPC-7351C was never released; the current IPC document is IPC-7352 (2023), and a profile for it is planned.
