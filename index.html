    Why standard footprint names?

    In most libraries the same package is drawn several times under different names. A name built from the package dimensions fixes that.

    The same QFN, four libraries
    • QFN32_5X5
    • QFN-32-EP
    • qfn32_0.5mm
    • U_QFN32_NEW2
    →
    One name that describes it QFN50P500X500X100-33N 0.50 mm pitch, 5 × 5 mm body, 1.00 mm max height, 32 pins + thermal pad, nominal density
    • Find before you draw

      The name is predictable, so you can search the library for it and reuse the footprint instead of building it again.

    • One package, one footprint

      No duplicates with slightly different pads. The library stays smaller and every board uses the same proven pattern.

    • Reviews catch wrong parts

      Pitch, body size, height and pin count are readable in the name, so a reviewer spots a 0.65 mm part placed on a 0.50 mm footprint before fabrication.

    • One language for every team

      The convention works the same in Allegro, Altium, KiCad or PADS, and new designers, assembly houses and customers can read it.

    • Height and variant are visible

      Maximum height supports 3D and enclosure checks, and the M / N / L letter shows which land pattern density was used.

    • Ready for automation

      Names built from data can be checked by scripts against the footprint geometry, so library errors are found automatically.

    Good to know: a standard name describes the package. It does not make the land pattern correct – pad sizes still come from the IPC calculations or your library rules.

    How it works

    Three steps from the datasheet table to a name your whole team can reuse.

    1. Pick the package family

      Search by package type. Each family asks only for the dimensions its name needs.

    2. Type the datasheet values

      Enter min and max as printed. The tool takes the nominal for spans and the maximum for height, the way IPC names are built.

    3. Copy and reuse

      Copy the name, share a link that reopens the same part, or download the JSON record for a footprint generator.

    Naming rules used

    How each number in the name is formatted. Every rule is covered by automated tests.

    ValueRuleExample
    Pitch, lead span, body, heightmm × 100, rounded half up, no leading zeros1.27 mm → 127, 0.50 mm → 50
    Chip body (RESC, CAPC, INDC …)One digit each side of the decimal point; further digits are dropped1.6 × 0.8 mm → 1608, 2.0 × 1.25 mm → 2012
    Which value is usedSpans and body sizes: nominal = (min + max) / 2. Heights and lead widths: maximumE 5.80–6.20 → 600, A max 1.75 → 175
    Pin quantityAfter a dash; a thermal pad counts as one more pin-33 for 32 pins + pad
    Hidden / deleted / reversed pinsUsed_package, package_used, R-20_24, -24_20, -20R
    Last letter, SMDDensity level M (most), N (nominal), L (least); none for BGARESC1608X55N
    Last letter, through-holeFabrication level A, B or CDIP762W52P254L1905H508Q14B
    Notes on the source and known issues

    Rules follow the public IPC-7351B naming convention summary (PCB Matrix, 2009). IPC-7351C was never released; the current IPC document is IPC-7352 (2023), and a profile for it is planned.
